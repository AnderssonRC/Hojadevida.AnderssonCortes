# Andersson Albarracin Cortes · Hoja de vida web

Sitio estático listo para GitHub Pages.

## Páginas
- `index.html`: página principal
- `hoja-de-vida.html`: hoja de vida
- `aula-como-taller.html`: El aula como taller
- `res-cogitans.html`: Res Cogitans

## Publicar en GitHub Pages
1. Sube **todos los archivos de esta carpeta** a la raíz del repositorio (Add file → Upload files).
2. En el repositorio, ve a **Settings → Pages**.
3. En *Source* elige **Deploy from a branch**, rama `main`, carpeta `/ (root)` y guarda.
4. En uno o dos minutos el sitio queda en `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`.

## Notas
- Los archivos locales llevan `?v=20261120`. Cuando cambies un `.js` o una imagen, sube ese número en los HTML para que el navegador no muestre la versión vieja.
- React, ReactDOM y Babel se cargan desde unpkg.com, y las fuentes desde Fontshare y Google Fonts, así que el sitio necesita internet.
- Para probarlo en tu computador usa un servidor local (por ejemplo `python -m http.server`), no abras el archivo con doble clic.
